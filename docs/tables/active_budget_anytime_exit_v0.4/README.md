## Storage policy

Committed: compact validation and holdout summaries, selected policies and optimisation histories, constraint checks, fairness audits, per-label comparisons, tables, figures, commands, theory, and paper-ready wording.

Not committed wholesale: complete candidate populations, full segment probabilities, parent score matrices, checkpoints, and feature caches. These remain reproducible from workspace outputs and branch scripts.
